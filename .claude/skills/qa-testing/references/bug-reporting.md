# Bug Reporting

## Required Format

### Title

Short, specific description of the problem.

### Severity

Choose:

- Critical
- High
- Medium
- Low

### Preconditions

Required setup before reproduction.

### Steps to Reproduce

Use deterministic numbered steps.

### Expected Result

Describe the correct behavior.

### Actual Result

Describe the observed behavior.

### Evidence

Include when useful:

- Screenshot
- Playwright trace
- Video
- Console error
- Network request/response

### Impact

Describe affected:

- Users
- Roles
- Features
- Data
- Workflows

### Regression

State whether a Playwright regression test should be added.

## Confirmed vs Potential

### Confirmed Bug

The behavior has been reproduced and contradicts expected behavior.

### Potential Risk

The behavior could cause a problem but has not been confirmed.

Never present a potential risk as a confirmed bug.
